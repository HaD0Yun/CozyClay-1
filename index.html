Why

A text prompt cannot hold a whole scene

AI video costs money per take, and one miss means paying again. A prompt cannot say where everyone stands, how they move, where the camera is and when it cuts.

Make those decisions first, in 3D, where they are cheap to change. The video model then gets the shot as a first frame, a greybox reference clip and a prompt that describes the real framing. It follows the blocking instead of guessing.

How it works

Stage, move, shoot, export

One local workspace that handles like a 3D editor, from the empty deck to the files a video model reads.

  1. Stage

    Build the set from primitives. Add rigged characters, or capsule stand-ins when nobody needs to move a limb.

  2. Move

    Describe the action. A deterministic compiler in the browser bakes every frame, and QA checks collisions, foot slide and reach.

  3. Shoot

    Put shots on a timeline, draw dolly rails and cranes, and look through the lens. Each shot knows the limits of the model you target.

  4. Export

    A keyframe pack with first and last frame, greybox clip, camera and prompt. Every edit, the agent's included, is one undo step.

FAQ

Questions

What is CozyClay?

Open source previs software in a browser: block a scene, pose characters, author camera moves and cuts, preview motion.

Previs or previz?

Same thing. Previsualization: the rough 3D pass where a shot gets blocked before anyone pays for final assets or renders.

Can I use it for camera control in AI video?

That is why it exists. Block the shot in 3D, then hand the camera move to the video model instead of describing it in a prompt. See camera control for AI video.

Do I need Blender, Unity or a GPU?

No. It runs in a Chromium browser with no GPU, Python or model download. Controls follow Unity conventions.

Can an AI agent drive it?

Yes. Use the agent panel in the studio, connect any MCP client with npx -y cozyclay mcp, or drive a running studio from the terminal with cclay live.

Is it free? Does it phone home?

Free, AGPL-3.0, runs on your machine and works offline. Project content is never uploaded. The npm package sends anonymous usage metrics; cclay telemetry off disables them.
