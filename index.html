Why

A text prompt cannot hold a whole scene

AI video costs money per take, and one miss means paying again. A prompt cannot say where everyone stands, how they move, where the camera is and when it cuts.

Make those decisions first, in 3D, where they are cheap to change. The video model then gets the shot as a first frame, a greybox reference clip and a prompt that describes the real framing. It follows the blocking instead of guessing.

How it works

Stage, move, shoot, export

One local workspace that handles like a 3D editor, from the empty deck to the files a video model reads.

  • Keyframe packFirst and last frame, greybox clip, camera, prompt
  • VideoThe shot as an mp4
  • PassesDepth and normal
  • Contact sheetThe shots side by side
  • OTIO cut listThe edit, for your editing software
  • StoryboardPanels with captions and an animatic
Direct it with AI

Your agent builds the scene while you watch

The same scene can be driven from three places, live in the viewport. Bring ChatGPT, Anthropic, OpenAI, Gemini, MiniMax, OpenRouter or CLIProxyAPI.

Chat beside the viewport and watch each change land. Sign in with ChatGPT or use your own key. Every change the agent makes is one undo step.

Open the studio, then press Cmd/Ctrl + B

Add CozyClay to Claude Desktop, Claude Code, Cursor or any MCP client. The agent edits the scene in the studio you have open.

{
  "mcpServers": {
    "cozyclay": {
      "command": "npx",
      "args": ["-y", "cozyclay", "mcp"]
    }
  }
}

Coding agents drive a running studio from the shell, JSON in and out.

npx cozyclay
cclay live status --wait
Quick start

One command

Node.js 22.19+ and a Chromium browser. The studio opens at 127.0.0.1:5180/app/.

Full control list → 
npx cozyclay --via site
git clone https://github.com/NomaDamas/CozyClay.git
cd CozyClay
npm install
npm run dev

Asking an AI agent to set it up? Give it the repository link; its instructions are in INSTALL_FOR_AGENTS.md.
